# Quizzes

Template de um quiz interativo em HTML, CSS e JavaScript, com interface em português.

## Funcionalidades observadas

- Modos de perguntas aleatórias, perguntas ainda não vistas e perguntas infinitas.
- Seleção do número de perguntas.
- Interface de resposta com feedback visual.
- Estimativa de duração e opção de reiniciar através do cabeçalho.

## Executar

Abre `template.html` diretamente num navegador moderno. Não existe configuração de dependências nem processo de build declarado no repositório.

## Estrutura

- `template.html` — estrutura, estilos e lógica da interface do quiz.

## Nota

O repositório contém um template isolado; não assumir que existe um banco de perguntas externo ou um processo de publicação configurado.
